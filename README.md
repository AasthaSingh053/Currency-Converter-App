# 💱 Currency Converter Desktop App

A simple and user-friendly **Currency Converter** built with **Python** and **Tkinter**.  
This desktop application allows users to convert between different currencies with real-time exchange rates.

---

## 🚀 Features
- Intuitive **Tkinter GUI** interface
- Convert between multiple currencies
- Real-time exchange rates (via API integration)
- Error handling for invalid inputs
- Lightweight and easy to run on any system

---

## 🛠️ Tech Stack
- **Python 3.x**
- **Tkinter** (GUI framework)
- **Requests** (for fetching exchange rates)
- **API**: [ExchangeRate API](https://exchangerate.host/) or similar
